Breast Cancer Detection Using Machine Learning

Project Overview
This project uses Machine Learning algorithms to classify breast tumors as Benign or Malignant based on diagnostic data.

Objectives
- Analyze breast cancer diagnostic data.
- Perform data preprocessing and feature selection.
- Train and evaluate Machine Learning models.
- Compare model performance using accuracy and classification metrics.

Dataset
- Wisconsin Breast Cancer Dataset
- 569 records
- 30 diagnostic features
- Two classes: Benign and Malignant

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Classifier
- Logistic Regression

Implementation
1. Dataset loading and exploration
2. Data preprocessing
3. Train-test splitting
4. Feature scaling
5. Model training
6. Prediction and evaluation
7. Feature selection
8. Model accuracy comparison

Machine Learning Models
- Random Forest Classifier
- Logistic Regression

Results
The models were evaluated using accuracy, classification reports, and confusion matrices. Feature selection was also performed to analyze model performance using the top 10 features.

Conclusion
This project demonstrates how Machine Learning techniques can be used to classify breast cancer diagnostic data and compare different classification algorithms.

Note:This project is developed for educational purposes only and is not intended for real medical diagnosis.
